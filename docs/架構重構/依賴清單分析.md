## STT 模型輕量化計畫

### 當前狀態
- **模型**: `openai/whisper-large-v3`
- **預估大小**: ~3GB
- **配置位置**: `modules/stt_module/config.yaml`

### 目標狀態
- **模型**: `openai/whisper-base`
- **預估大小**: ~140MB
- **性能權衡**: 準確度略降 (~5-10%)，但速度提升 3-4 倍

### 替代方案
```yaml
# 選項 1: Whisper Base (推薦)
whisper_model_id: "openai/whisper-base"

# 選項 2: Whisper Small (平衡)
whisper_model_id: "openai/whisper-small"

# 選項 3: 使用 faster-whisper (未來)
# 需要額外整合 CTranslate2
```

## 前端解耦策略

### 階段一：配置開關 (本階段)

在 `configs/config.yaml` 新增：
```yaml
# 引擎模式配置
engine:
  mode: "engine-only"  # "full" | "engine-only"
  
  # 模組啟用開關
  modules:
    frontend_enabled: false
    ui_enabled: false
    ani_enabled: false
    mov_enabled: false
```

### 階段二：程式碼隔離

修改關鍵檔案：
1. `core/system_initializer.py` - 根據配置跳過前端模組
2. `core/controller.py` - 移除前端相關事件訂閱
3. `Entry.py` - 新增 `--engine-only` 命令列參數

### 階段三：依賴清理

建立新檔案：
- `requirements-engine.in` - 純引擎依賴
- `requirements-frontend.in` - 前端額外依賴
- `requirements-dev.in` - 開發工具

## 風險評估

### 🔴 高風險
- **前端完全解耦可能影響某些事件流** - 需仔細檢查 Event Bus 訂閱
- **部分模組可能隱性依賴 PyQt5** - 需全面搜尋

### 🟡 中風險
- **Whisper 模型降級可能影響辨識準確度** - 需實際測試繁體中文效果
- **部分依賴可能被多個模組共用** - 需謹慎移除

### 🟢 低風險
- **開發工具移除** - 不影響生產環境
- **配置檔調整** - 可輕易回滾
