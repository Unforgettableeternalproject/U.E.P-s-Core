# Phase 1.5 驗收評估：完備性與可利用性（2026-08-07）

自動化 concept / procedure 抽取之前的驗收關卡。兩個問題：
語料抽得夠不夠完整、抽出來的東西 agent 能不能實際用上。

## A. 完備性 —— 粗篩訊號沒有鑑別力

「同一檔案在相鄰 human 輪被再次修改」這個訊號，對照隨機抽樣的非候選輪對：

| | 候選組 | 對照組 |
|---|---|---|
| 組數 | 78 | 26 |
| 產出 concept | 55 | 18 |
| 產出率 | **0.705 條/組** | **0.692 條/組** |
| 通過校準（surprisal >= 0.8） | 22 | 6 |
| 通過率 | 40% | 33% |
| VOLUNTEER（模型本來就會）率 | **18%** | **11%** |
| 有效產出率 | 0.282 條/組 | 0.231 條/組 |

對照組是從 477 組「無檔案重疊的相鄰 human 輪對」隨機抽的（固定 seed 20260807），
用**完全相同**的蒸餾指示與批量跑，唯一的差別是候選來源。

**結論：訊號等於隨機抽樣。** 產出率差 2%，有效產出率差距也在小樣本的雜訊範圍內
（對照組只有 18 條，6 條通過）。更難堪的是**候選組的廢料率反而更高**（18% vs 11%）——
訊號篩出來的東西不但沒有比較好，還多了一點雜訊。

事後看原因不難理解：「檔案被改兩次」預設了「第一次沒改對」，
但實際語料裡它更常對應到「這是個多輪的大任務」——而大任務的每一輪都可能藏著知識，
沒有大任務的輪次同樣可能藏著知識。這個訊號量到的是**工作量**，不是**錯誤**。

### 完備性推估

```
母體：78（候選）+ 477（對照母體）= 555 組相鄰 human 輪對
有效產出率：約 0.25 條/組
全語料潛在有效 concept：約 139 條
目前實得：22 條 → 覆蓋率約 16%
```

**目前的抽取遠遠不完備**，但瓶頸不是訊號設計，是覆蓋範圍。
既然篩選沒有鑑別力，那就沒有值得優化的篩選——要嘛全跑，要嘛接受低覆蓋率。

## B. 可利用性 —— 22/22 APPLIED，但這個數字要小心解讀

對通過校準的 22 條做注入實驗。設計要點：

- **每題注入 5 條記憶（1 條目標 + 4 條跨專案干擾）**，不標示哪條是目標。
  只注入一條答案再問同一題，測到的是複述不是利用。
- 干擾項充當**安慰劑控制**：若行為改變只是因為「有東西被注入」，
  會表現成拿無關記憶亂套。
- 對照組是現成的——這 22 題的無注入回答就是 Phase 1.5 行為測試的原始資料。
- 判定的關鍵界線在 `APPLIED` 與 `RECITED`：**結論有沒有因此改變**。

結果：

| 判定 | 條數 |
|---|---|
| `APPLIED` | **22** |
| `RECITED` | 0 |
| `IGNORED` | 0 |
| `MISAPPLIED` | 0 |

判卷理由顯示是實質的結論翻轉，不是複述：

- `c-038`：從「改 identity key 生成邏輯」→「不改 key、加 fallback」
- `c-043`：從 `message.id` → `(prompt_id, turn_index)` 複合鍵
- `c-052`：從「容量通常不是大問題」→「已逼近上限、需嚴格評估」
- `c-004` / `c-019` / `c-028`：舊回答的推測結論被直接反轉

**零 MISAPPLIED**：4 條跨專案干擾記憶一次都沒被誤用。安慰劑控制通過。

### ⚠️ 這個 100% 高估了真實效果

`probe` 是蒸餾階段**為了測試該條記憶而量身設計的**，題目與記憶高度對齊。
真實情境裡，記憶與當前任務的相關性遠不會這麼高。

所以這個實驗證明的是：**只要檢索把對的記憶送到面前，agent 就能用得上、
而且不會被無關記憶干擾**。

它**沒有**證明：檢索能不能把對的記憶找出來。

## 對自動化的結論

1. **可利用性關卡通過**，但通過的是「利用」不是「檢索」。
2. **完備性關卡沒過**：覆蓋率約 16%，且篩選機制無效。
3. **瓶頸不在抽取，在檢索。** 抽取的召回率問題可以用「全跑」暴力解決（純成本問題），
   但檢索準確率**從未被測量過**，而注入實驗的 100% 正是建立在「檢索完美」的假設上。

因此**不建議現在就自動化抽取**。先驗證檢索：
拿現有 22 條建索引，用真實的開發問題（不是量身設計的 probe）去召回，
量「該被召回時召回了嗎」與「召回的是相關的嗎」。
那個數字才決定整套系統的實際價值——抽 139 條而檢索召不出來，跟抽 22 條沒有差別。

## 已知限制

- 對照組只有 18 條 concept / 6 條通過，通過率 33% 的信賴區間很寬
- 對照組與候選組由不同批 subagent 蒸餾，蒸餾者之間的變異未控制
- 注入實驗每題固定 4 條干擾項，真實召回的雜訊比例未知
- 判卷全部單一評審，跨評審一致性未量
